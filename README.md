# Gemini Share Hub 🌟

לוח קהילתי חופשי לשיתוף מנויי **Google One** ו-**Gemini Advanced** (Google AI Premium) בישראל.

המערכת מאפשרת לבעלי מנוי שיש להם מקומות פנויים בקבוצת המשפחה (עד 5 מקומות), ולמשתמשים המחפשים להצטרף לשיתוף, להתחבר בקלות, ביעילות ותוך שמירה מלאה על פרטיות.

---

## תכונות מרכזיות ✨
- **לוח דו-כיווני**: מציגים מודעות של "מציעי שיתוף" ושל "מחפשי שיתוף".
- **פרטיות מובנית**: הסבר מודגש על כך ששיתוף משפחתי בגוגל אינו חושף קבצים, מיילים ב-Gmail או היסטוריית שיחות ב-Gemini.
- **הסרת מודעות בטוחה**: מחיקה אוטומטית באמצעות קוד סודי אישי (PIN בן 4 ספרות) שהוגדר בעת הפרסום.
- **כפתורי פעולה מהירים**:
  - העתקת כתובת מייל ללוח בלחיצה אחת עם משוב ויזואלי.
  - כפתור פתיחת אימייל ישיר (`mailto`).
  - כפתור וואטסאפ מהיר (אם המפרסם הזין מספר טלפון).
- **סינונים וחיפוש**: סינון לפי סוג מודעה (מציע/מחפש), סינון לפי עלות (חינם/חלוקת עלויות), וחיפוש טקסטואלי חופשי.
- **הגנת ספאם**: מלכודת בוטים (Honeypot) והגבלת קצב פרסום.
- **ממשק מודרני מותאם מובייל**: עיצוב RTL בעברית מלאה.

## הוראות הרצה מקומית 🚀

1. פתח טרמינל בתיקיית הפרויקט:
   ```bash
   cd C:\Users\Eli\.gemini\antigravity\scratch\gemini-share-hub
   ```

2. התקנת תלויות (אם טרם הותקנו):
   ```bash
   npm install
   ```

3. הפעלת השרת:
   ```bash
   npm start
   ```

4. פתח את הדפדפן בכתובת:
   👉 **[http://localhost:3000](http://localhost:3000)**

## העלאה לענן (פריסה חינמית ב-Render) ☁️
האתר מוכן לפריסה ב-Render או Railway:
1. העלה את תיקיית הפרויקט למאגר GitHub.
2. ב-Render, צור **Web Service** חדש וחבר את המאגר.
3. הגדרות שירות:
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Environment Variable**: `PORT=10000` (או ברירת המחדל של Render)
4. האתר יהיה זמין בכתובת ציבורית עם תעודת SSL מאובטחת.
